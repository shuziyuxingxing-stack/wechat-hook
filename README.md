# wechat-hook
这是一个微信hook（适用4.1.15.56 for PC)，实现了文本、图片、语音、拍一拍、文件、表情包的接收与发送，以及主动引用、被@响应。可检索联系人、朋友圈。基本实现微信全部功能（不包括支付）。

wechathook可用于制作微信bot，实现在微信里“养大肥鱼”。

工作原理是当收到入站信号，AI通过hook，调用微信原生函数发送图片或文字或拍一拍，营造AI接管了账号的效果。

本人倾向于这样操作：把本hook接入astrbot使用。也就是说，真正的决策和执行者放到astrbot内，由astrbot内配置的AI选择如何回复、调用何种函数回复，再提供本hook作为“手脚架”供其调用。这样的好处是astrbot内的QQ渠道、飞书渠道、微信渠道乃至其他渠道可以共用同一个知识库、人格设定、日志面板和系统管理。
